# COVID-19 Data Analysis & Interactive Dashboard

## Project Overview

This project analyzes global COVID-19 data to identify trends and patterns in cases, deaths, and case fatality rates across countries and continents.

The analysis combines SQL, Python, Pandas, Excel, and Power BI to clean, analyze, visualize, and present insights from more than 429K records across 255 locations.

## Project Objectives

- Analyze COVID-19 cases and deaths across countries and continents
- Calculate and compare case fatality rates
- Identify countries with the highest reported cases and deaths
- Analyze daily and yearly trends
- Identify peak daily cases across countries
- Compare the impact of COVID-19 across continents
- Build an interactive Power BI dashboard to present key findings

## Tools & Technologies

- SQL
- Python
- Pandas
- Excel
- Power BI
