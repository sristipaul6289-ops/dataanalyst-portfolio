# COVID-19 Data Analysis & Interactive Dashboard

## Project Overview

This project analyzes global COVID-19 data to identify trends and patterns in cases, deaths, and case fatality rates across countries and continents.

The analysis combines SQL, Python, Pandas, Excel, and Power BI to clean, analyze, visualize, and present insights from more than 429K records across 255 locations.

---

## Project Objectives

- Analyze COVID-19 cases and deaths across countries and continents
- Calculate and compare case fatality rates
- Identify countries with the highest reported cases and deaths
- Analyze daily and yearly trends
- Identify peak daily cases across countries
- Compare the impact of COVID-19 across continents
- Build an interactive Power BI dashboard to present key findings

## SQL Analysis

The SQL analysis focused on exploring COVID-19 trends, comparing countries and continents, and calculating key metrics.

### Key Analysis Performed

- Calculated total COVID-19 cases and deaths
- Calculated case fatality rates (CFR)
- Analyzed new cases and new deaths over time
- Compared COVID-19 impact across countries
- Compared COVID-19 statistics across continents
- Identified countries with the highest total cases
- Identified countries with the highest total deaths
- Identified the highest daily cases recorded by each country
- Analyzed yearly COVID-19 trends
- Used CTEs and aggregate functions for multi-step analysis
- Used JOINs to combine calculated results with the original dataset
- Used date-based analysis to identify trends over time

### SQL Concepts Used

`SELECT` · `WHERE` · `GROUP BY` · `ORDER BY` · `HAVING` · `JOIN` · `CTE` · `CASE` · `NULLIF` · `ROUND` · Aggregate Functions · Date Functions
