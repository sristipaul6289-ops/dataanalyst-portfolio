Supply Chain Data Analysis Using Python

Python | Pandas | NumPy | Matplotlib | Seaborn

Analyzed supply chain data to evaluate sales, profitability, customers, products, markets and delivery operations.

  • Analyzed 180,519 order-item records covering 65,752 orders, 20,652 customers and 118 products.
  • Performed data cleaning, validation, feature engineering and exploratory data analysis.
  • Calculated sales, profit, profit margin, order value, delivery time and shipping delays.
  • Identified 98,977 late order items and a 56.98% repeat-customer rate.
Key Insight: Europe generated the highest sales at approximately $10.87M, while Fishing was the top-performing category with approximately $6.93M sales and $756K profit.

COVID-19 Data Analysis & Interactive Dashboard

SQL | Python | Pandas | Excel | Power BI

Analyzed global COVID-19 data to understand cases, deaths, infection rates, case fatality rates and time-based trends.

  • Analyzed 429K+ records across 255 locations.
  • Used CTEs, JOINs, subqueries, GROUP BY, HAVING, FILTER, aggregations and date functions.
  • Used LAG() for year-over-year analysis and time-based comparisons.
  • Built an interactive Power BI dashboard with KPIs, rankings, trends and slicers.
Key Insight: The analysis highlighted differences in COVID-19 cases, deaths and trends across countries and continents.

E-Commerce Sales & Profit Analysis Dashboard

Excel | Power Query | PivotTables | PivotCharts | Slicers

Built an interactive Excel dashboard to analyze sales, profit, orders, customers, products, discounts, shipping modes, regions and customer segments.

  • Cleaned and transformed raw data using Power Query.
  • Developed six KPIs: Total Sales, Total Profit, Total Orders, Total Quantity, Average Order Value and Profit Margin.
  • Used PivotTables, PivotCharts, formulas and slicers for business analysis.
  • Analyzed categories, customer segments, shipping modes and regional performance.
Key Insight: Technology was the top category with approximately $5.98M in sales. Consumer was the leading segment with approximately $6.50M sales, while Regular Air generated approximately $7.51M sales.
