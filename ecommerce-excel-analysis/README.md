# E-Commerce Sales & Profit Analysis Dashboard

## Project Overview

An interactive Excel dashboard designed to analyze e-commerce sales, profitability, customers, products, shipping methods, discounts, and regional performance.

## Tools Used

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Excel formulas
- Slicers

## Key Analysis

- Sales and profit KPIs
- Sales by product category
- Profit by sub-category
- Top 10 products by sales
- Top 10 products by profit
- Customer segment analysis
- Discount vs. profit analysis
- Shipping mode analysis
- Regional analysis

## Dashboard Features

- 6 KPI cards
- Interactive Region slicer
- Interactive Customer Segment slicer
- Interactive Ship Mode slicer
- Multiple interactive charts

## Key Insight

Technology generated the highest sales among the three product categories in the analyzed dataset, while discount levels showed a noticeable impact on profitability.
